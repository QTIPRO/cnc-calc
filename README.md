# Калькулятор стоимости ЧПУ (офлайн)

Простое офлайн-веб-приложение для расчета стоимости изготовления деталей на ЧПУ станках.

## Возможности
- Параметры партии: количество, валюта
- Материал: пресеты и своя цена за кг, масса детали, процент отходов/запас
- Машинное время: наладка (на партию), цикл (на деталь), ставка станка
- Доп. затраты: инструмент/оснастка, пост-обработка, доставка
- Наценки: накладные, маржа, НДС
- Живые пересчеты, сохранение параметров в `localStorage`
- Экспорт/импорт настроек в JSON

## Запуск
1. Откройте файл `index.html` двойным кликом (интернет не требуется).
2. Введите свои параметры — результаты обновляются мгновенно.

## Формулы (кратко)
- Закупочная масса/деталь = масса_чистой_детали × (1 + отход_%/100)
- Стоимость материала/деталь = закупочная_масса × цена_за_кг
- Время станка (часов) = (наладка_мин + цикл_мин × количество)/60
- Стоимость станка/деталь = ставка_за_час × время_станка / количество
- Доп. затраты/деталь = инструмент_шт + пост_шт + оснастка_партия/кол-во + доставка_партия/кол-во
- Себестоимость/шт = материал + станок + доп
- После накладных = себестоимость × (1 + накладные_%/100)
- Перед НДС (с маржой) = после_накладных × (1 + маржа_%/100)
- Цена с НДС = перед_НДС × (1 + НДС_%/100)

## Примечание
- Все данные хранятся только локально в вашем браузере.
- Значения и пресеты демонстрационные — замените на свои реальные.
